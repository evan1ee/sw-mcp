# ADR-024: Requirements target functional features

- **Status:** Proposed — Builder's call
- **Source:** specification v1.9, section 19

## Decision

Requirements target functional features; Part Feature Graph nodes declare what they `realize`; existing parts get a read-only Part Feature Graph

## Rationale

Keeps the intent independent of modeling strategy; one path for IR-built and hand-modelled parts

## Where it applies

- Section 19 only.
