# ADR-026: Task-driven IR composition

- **Status:** Accepted
- **Source:** specification v1.9, section 19

## Decision

Task-driven IR composition: shared core plus optional, independently usable modules; a task submits only the modules it needs as an IR bundle

## Rationale

Simple part requests stay simple; assemblies, requirements and drawings are added only when the task needs them
