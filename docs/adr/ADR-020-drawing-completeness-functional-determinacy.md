# ADR-020: Drawing completeness = functional determinacy, with parameter coverage as proxy

- **Status:** Accepted
- **Source:** specification v1.9, section 19

## Decision

Drawing completeness = functional determinacy, with parameter coverage as proxy

## Rationale

Modeling dimensions are not manufacturing dimensions; 1:1 parameter coverage passes useless drawings and fails good ones

## Where it applies

- Section 19 only.
